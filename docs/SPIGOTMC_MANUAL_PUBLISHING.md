## Why This Is a Free Resource

Reload is a compact, single-purpose administration utility. It has no paid backend, account service, premium integration, bundled commercial content, database, economy or transaction system. Publishing it free under the MIT License is proportionate to its scope and makes the source and release artifact easy to audit.

## Important Warnings

- The SpigotMC resource page, documentation and support channel are English-only. Chinese-language support is not provided on SpigotMC.
- The plugin itself currently uses Chinese configuration comments, command feedback and console messages.
- Claim support for Paper 26.2 only. Do not claim tested support for Spigot, Folia or other implementations.
- The 1.0.2 artifact passed a clean Maven build. No additional live-server test was performed for the Paper 26.2 compatibility release or this documentation-only update.
- Configured commands run with full server-console authority. Highlight this prominently on the resource page.
- Do not upload `.idea`, `*.iml`, `target`, source archives containing local files, or temporary files.
- Do not state that the plugin stores player data or supports transaction rollback; it does neither.

## Manual Publish Steps

1. Sign in to SpigotMC and open the resource creation form.
2. Choose a free resource and set the price to USD 0.00.
3. Enter the suggested title, tag line, version, category and platform details.
4. Upload `target/Reload-1.0.2.jar`.
5. Paste `docs/SPIGOTMC-RESOURCE.md` into the main resource description using BBCode mode.
6. Paste `docs/SPIGOTMC-RESOURCE-BBCODE.txt` into the documentation area, or publish it as the complete documentation section supported by the form.
7. Add the GitHub source, release, issue tracker and MIT License links.
8. Recheck that the English-only support notice appears in both pasted documents.
9. Verify the uploaded filename, version and supported platform before submitting.
10. Publish manually and keep the SpigotMC resource URL for the next README or Release update.
